# 规则 40：出口闸门（里程碑）

> 闸门项与判据来源：§11（阶段出口标准）、§11.2（回归项）、§10.4（键表三态）、§13（验收）、`docs/measurements.md`（实测登记）。

## 1. 出口的四个必要条件（全过方可出口）

1. **指标**：§11 该阶段出口标准全部落定；§13 对应行的复现方式可跑通并产出报告。
2. **回归**：§11.2 该阶段行的回归项**全过**；不得用"下一阶段补跑"顶替。
3. **配置**：§10.4 中"定稿时点 = 本阶段及之前"的键**零空缺**（空值 = 未定稿，禁止留默认值顶替）；`provisional` 项按三态规则清零。
4. **登记**：`docs/measurements.md` 中"阻塞里程碑 = 本阶段"的行**必须已回填**且结论值 + 依据报告路径 + 复检时点三列完整；**未回填即视为未定稿，本阶段不得出口**。

## 2. 构建与代码闸门

- 构建**零告警**（新增告警视为回归）。
- `realtime_apply` 等 pybind 扩展：模块后缀取自 `python3-config --extension-suffix`，**不得手工命名**；每轮构建跑 U8 / FP16 两档数值一致性检查（§11.2）。
- 接口签名与 §5 契约 C 节逐字一致；偏离即判回归。

## 3. 文档闸门

- 本轮所有裁定、实测、偏离已按 `00-ssot.md` §4 的回写义务完成回写（正文 + §10.4 + §14 + §15 + 附件规范）。
- 新建 / 删除子文档已完成 §10.3 与 §14 登记（无孤儿文档）。

## 4. 执行方式

出口自检产出一份**闸门清单**：逐条列出闸门项 → 状态（过 / 未过）→ 证据路径（报告文件或配置键）→ 责任人（实现者自测 / 验收人复核）。**未过项不得以文字说明代替证据路径**。

## 5. 阻塞处置

- 闸门未过时，**不得开始下一里程碑的实现**；只允许做"解除阻塞"的动作（补测、补报告、走 §15 裁定）。
- 需要放宽验收上限时，必须走 §15 裁定并回写 §13，禁止在实现中默认放宽。
