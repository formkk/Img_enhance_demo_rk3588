# 规则 20：契约白名单

> 三张白名单的来源节号即唯一权威，本规则**不列出具体取值**，只规定"查哪里、不许自造"。

## 1. 三张白名单

| 类别 | 唯一来源 | 纪律 |
|---|---|---|
| 返回码 | 主基准 §5 契约 A 节 | 打印**符号名**；缺失类别须先走主基准变更再使用 |
| 日志 `event` | `docs/logging.md` §4 事件清单 | 小写 + 下划线；**不得自造未登记事件**；必带字段按该表 |
| config 键 | 主基准 §10.4 键表 | 键不存在即未定稿；禁止在代码里出现表外键 |

## 2. 时钟与标识

- 时序比对只用 `mono_ns`（`CLOCK_MONOTONIC`）；`utc_iso8601`（`CLOCK_REALTIME`）仅供人读与回放。
- `seq` 由 TH1 分配且单调递增，**下游不得重编号**；缓冲交换与 pageflip 回调必须保留该 `seq`。
- 带帧事件必须带 `seq_src` 或 `seq_est`；带状态事件必须带 `rsm=` 与 `fsm=`。

## 3. 接口与数据结构

- 字段类型 / 单位 / 所有权，以及各模块函数签名与返回码，一律以 §5「接口与数据结构契约」B、C 节为准（本规则不复制签名）。
- 所有权硬契约：仅 TH1 持有 `QBUF` 权；消费者只持 lease；**任何模块不得 `close(dmabuf_fd)`**。

## 4. 运行期可改性

- 现场运行期**只允许**曝光 / 增益微调；预设与其余 ISP 参数由启动时选定，换值 = 改 config 后重启。
- 禁止现场手改 `config.yaml` 取值以"先把演示跑起来"；取值来源见 §10.4「取值来源 / 依据」列。

## 5. 状态机

- 合法迁移与非法迁移处置以 §5 的 RSM / 触发 FSM 表为准；非法迁移返回 `E_STATE`，禁止绕过状态机直接改状态。
- 术语统一使用 `MIPI_PREVIEW_ONLY`；"降级态"等旧称不得出现在代码、日志与文档中。
