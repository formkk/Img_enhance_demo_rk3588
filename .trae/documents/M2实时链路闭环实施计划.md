# M2 实施计划：实时链路闭环（MIPI-only）

## Context

**为什么做这件事**：M0 已于 v3.57 出口；用户选定「M2 实现开工」。开工前存在一处闸门张力——规则 `40-gate.md` §5 规定「闸门未过时不得开始下一里程碑的实现」，而 **M1（相机链路）尚未出口**。该张力已由 **v3.60 裁定 O53** 解除：**M1 与 M2 并行开工、各自出口互不阻塞**，但 **M2 出口仍依赖 M1 产出的空链路基线（`metrics.idle_link_baseline`）与 O19 结论**。

**现状缺口**：仓库里**没有任何 Python 交付模块**（`capture.py` / `curve_estim.py` / `realtime_apply.py` / `display_mipi.py` 均不存在）、**没有 CMakeLists/Makefile**、**没有任何 pybind11 源码**。唯一的可运行实时链路是单体 C 探针 `tools/pipeline_probe.c`（v3.47，1118 行，已实测 2400 帧 / 零丢 flip / NEON 与标量逐位一致）——**它是探针不是交付链路**，不吃 config、不记日志、不实现 lease/状态机/OSD/按钮。

**目标**：按主基准 §10.3 的代码结构与 §5 的接口契约，把探针拆成 4 个交付模块 + pybind 扩展，闭环 §11 M2 行的出口标准（MIPI 双窗 P50 ≥25 FPS、P95 延迟 ≤80 ms、切换响应 ≤500 ms、`bench.py` 报告齐全、§10.4 M0~M2 非 HDMI 键全定稿）。

**范围边界**（§11 M2 行，v3.48 裁定 O49 重划）：**TH1 + TH2a/2b + TH4**。
**不含**：`display.hdmi_mode_selection` 与 `RUN_DEMO ↔ MIPI_PREVIEW_ONLY` 迁移（→ **M2-1**，需 HDMI 显示器接入）；HQ 定版与四个 HQ 键（→ **M2-2**）。「触发HQ」在 M2 内**仅作功能演示**（走 §3.5 的 `MIPI_PREVIEW_ONLY` 全宽弹层 2.5 s，**画质/耗时不作达标判定**）。

## 0. 一处须你确认的布局判断

§10.3 的结构树以 `starlight_demo/` 为根，其第二层同时含 `config.yaml` / `main.py` / `capture.py` … **与** `docs/` / `tools/` / `environment/` / `.trae/`。而后者现全部位于**仓库根**。故本计划按**字面读法**执行：

- **交付模块放仓库根**（与 `config.yaml`、`tools/`、`docs/` 同级），**不新建 `starlight_demo/` 子包**；
- `config.yaml` **保持在仓库根不动**（§10.4 明文「本表的唯一落盘载体是仓库根 `config.yaml`」），避免复制取值造成双 SSOT；
- 新增 `deploy/starlight-demo.service`（§10.6-A）。

> 若你更希望新建 `starlight_demo/` 子包，请在批准时指出——这只是文件位置差异，不影响任何后续步骤的内容。

## 1. 分阶段实施

### S0 基座：config 加载 + 日志 + 构建系统

| 产出 | 说明 |
|---|---|
| `config.py` | 加载仓库根 `config.yaml`；**按 §10.4 键表做白名单校验**（表外键即报错，规则 `20-contracts.md` §1）；提供只读快照与快照哈希（§6.5 测量条件随行） |
| `log.py` | 按 `docs/logging.md`：级别 / 目录 / 轮转 / 行格式 `<utc_iso8601> <mono_ns> <level> <module> <event> [k=v]`；**event 仅取 §4 白名单**；**错误码仅取 §5 契约 A**（`OK` / `E_V4L2` / `E_NPU` / `E_DRM` / `E_IO` / `E_STATE` / `E_TIMEOUT`），打印符号名；日志写失败不得阻塞主链路 |
| `CMakeLists.txt` + `build/` | 按 `docs/build.md` §2/§3：`-O3`、`-march=armv8.2-a+fp16 -mcpu=cortex-a76.cortex-a55`、`-Wall -Wextra` **零告警**；`-ffast-math` **仅热路径**；目标 = `realtime_apply` 扩展（+ 可选 `bench_cli`）；构建时打印 toolchain / CMake / pybind11 / librknnrt 版本 |

**验收**：`python3 -c "import config, log"` 成功；表外键注入被拒；构建零告警。

### S1 `realtime_apply` pybind 扩展（C/NEON）

**复用**：`tools/pipeline_probe.c` 的 `build_taps`(L391) / `apply_fused_neon`(L405) / `apply_fused_scalar_to`(L475)，以及 `tools/apply_probe.c` 的标量参考。

**改造要点**：
- 现实现依赖模块级全局（`W/H/CW/CH/g_src/g_curve/g_out`）⇒ 必须改为**显式参数**，做成**无状态、可重入**（`docs/design/realtime_apply.md` §1/§2）。
- 导出签名**逐字对齐 §5 契约 C 节**：
  - `apply_window(const uint8* rgb, const void* curve, uint8* dst, uint32 w, uint32 h) -> int`
  - `apply_full(const uint8* nv12, const void* curve, uint8* dst_rgb, uint32 w, uint32 h) -> int`
- **U8 / FP16 双精度由参数选择，禁止写死任一种**（`pipeline.curve_field_precision` 定稿时点 = M2，O23）；中间计算域统一 `float32`。
- 单遍融合不变量：每目标像素**只采样一次**曲线场；禁止逐迭代独立读写。
- stride 一律按调用方传入，**禁止按 `w × 3` 推算**。
- 热路径不分配。
- pybind11 **锁定 2.11.x**；模块后缀取自 `python3-config --extension-suffix`，**禁止手工命名**（`docs/build.md` §4）。

**验收**：`python3 -c "import realtime_apply"`；签名与 §5 C 节逐字一致；**U8 / FP16 两档数值一致性检查**；NEON vs 标量**逐位一致**；`bench.py apply-micro --impl native` 由 `not_implemented` 转为可跑，且 **@512×288 ×8 iter 不得劣于 M0 基线**（§6.1 该行 ≤20 ms）。

### S2 `capture.py`（TH1）

**复用**：`pipeline_probe.c` 的 `cap_init`(L180) / `cap_qbuf` / `cap_stream_on` / `cap_dqbuf` / `cap_deinit`(L312)（MPLANE + `EXPBUF` 零拷贝；`b.length` 在 MPLANE 下 = plane 个数；`EXPBUF.plane` 显式写 0）。

**新增（探针没有的契约部分）**：
- **DMABUF 池 + lease**：`acquire_frame(consumers[], FrameDesc*)` 为每个消费者签发 lease；`release_lease(lease_id)` 引用计数归零后才允许 `QBUF`；**任何模块不得 `close(dmabuf_fd)`**；无可用缓冲时丢**最旧的未签发 lease** 帧，**禁止强制回收在用 lease**。
- **`seq` 唯一分配者**（单调递增，下游不得重编号）；`generation` 每次 `QBUF` 自增。
- **`stream_on_once()` 计数在进程内恒为 1**；软复位**不 `STREAMOFF`、不释放池/CRTC/plane**（O26 口径）。
- **四源触发 FSM**（`IDLE` / `DEBOUNCE` / `HQ_BUSY`）+ `trigger.debounce_ms` 消抖；`HQ_BUSY` 期间触发**一律丢弃并计数**，不排队、无 pending 位；`submit_trigger(source)` 返回 `seq_src`，丢弃返回 0。
- **evdev 触控**（3 键；触控设备节点需板上只读探测确认）。
- 时间戳：读 `V4L2_BUF_FLAG_TSTAMP_SRC_MASK` 判定 **SOE / EOF**（§6.5）。

**验收**：`stream_on_once` 事件在进程内**不出现第二次**；lease 无泄漏（引用计数归零）；状态机合法迁移可达、非法迁移返回 `E_STATE` 且零穿越（§11.2 M2-①）。

### S3 `curve_estim.py`（TH2a）

**复用**：`pipeline_probe.c` 的 `rga_init`(L333) / `rga_blit_nv12`(L371)（`dma_heap(system-dma32)` + **偏移基址子视图** + 一次 `improcess` 完成 scale+CSC；pad 在缓冲初始化时一次填零，因 `imfill` 对 RGB888 失败、`drect` y 须偶对齐）、`slice_build_input`(L524) / `slice_worker`(L542) / `npu_init`(L570) / `npu_estimate`(L615)（双 context、`RKNN_NPU_CORE_0` / `CORE_1`、HALO=7、**mutex+cond+代次**会合——**不要用 `pthread_barrier`**，探针首版即因它退出死锁）。

**新增**：`publish_curve(const CurveSnapshot*)` **双缓冲发布**（读侧只用最新完整版）；EMA `α` 取自 config（`pipeline.ema_alpha`）；`estimate()` 低频（5~15 Hz，`pipeline.est_freq_hz`）。

**验收**：曲线场与探针输出**逐位一致**；`f_est` 落在契约区间；HQ 未启用时不涉及分核退化。

### S4 `display_mipi.py`（TH4）

**复用**：`pipeline_probe.c` 的 `drm_open_connector`(L692) / `drm_create_fb_rgb888`(L738) / `drm_init` / `drm_set_crtc` / `drm_flip`(L789) / `drm_wait_flip`(L811) / `canvas_compose`(L862)。

**要点**：**DRM 单 CRTC（DSI）**；connector / CRTC **一律运行时解析，禁止写死 crtc id**；画布 `1024×600` / `DRM_FORMAT_RGB888` / stride 3072；pageflip 用 `DRM_MODE_PAGE_FLIP_EVENT` + `drmHandleEvent`；**显示时间戳取 vblank（drmEvent），不取提交时刻**；`compose_flip(enh_win, raw_win, ControlState*)` 按 §5 C 节签名，过期帧丢弃。

**验收**：双窗出图；`pageflip_ms` / `canvas_ms` 打点；零丢 flip；HDMI 缺席不阻塞主链路（RSM 进入 `MIPI_PREVIEW_ONLY`）。

### S5 OSD 指标区 + 按钮区

| 产出 | 说明 |
|---|---|
| `osd.py` | §3.4 布局：画布 1024×600 = 两窗 512×288 + **OSD 指标区 1024×216**（状态/数值行 1024×36 + 图示区 1024×180）+ 按钮区 1024×96。**8 字段 4 区**；图示区 = tone-mapping 曲线图（R/G/B 三线 + 对角参考）+ 亮度直方图（原图灰 / 增强绿叠加，256 bin）。统计**降采样 4×**（512×288 → 128×72 = 9,216 样本）+ **降频 1 Hz**（`ui.osd_stats_decimate=4` / `ui.osd_stats_hz=1`）。**PSNR/SSIM 一律不入实时 OSD** |
| `ui_buttons.py` | 3 键（触发HQ / 存图 / 复位·退出），行高 96 px、各 341 px，命中区 ≥ `ui.hit_area_min_px=67`；复位键短按 = 软复位、长按 ≥3 s = 退出进程（`ui.reset_hold_ms=3000`） |

**★ O44 收口**：OSD 三项实测耗时（统计 / 曲线图 / 直方图）在此实测并回填 **§3.4 + §6.1**（**不新开 `docs/measurements.md` 行**），据此判定 §6.1 的 `MIPI 画布合成 + OSD ≤6 ms` 行是否需拆分或重排。

**验收**：`bench.py --capture-mipi` 截图 + 8 字段真值核对 + 两块图示存在性；3 键逐一点按各 ≥3 次。

## 2. 硬约束清单（违反即判未达标）

1. **8 次迭代必须单遍融合**——未融合即判未达标，不得以「编译器会自动优化」免检（§3.3、规则 `30-board-safety.md` §3）。
2. **仅 TH1 持 `QBUF` 权**；消费者只持 lease；**任何模块不得 `close(dmabuf_fd)`**。
3. **全生命周期只 `stream on` 一次**；软复位不 `STREAMOFF`。
4. **禁止写死 crtc id**（connector/CRTC 运行时解析）。
5. **config 表外键禁止**；**event 不得自造**；**返回码只取 §5 A 节符号名**。
6. **禁止 CPU 全帧混合**做淡入淡出。
7. 构建**零告警**；pybind 后缀**取自 `python3-config --extension-suffix`**。
8. **`realtime_apply` 不得劣于 M0 基线**（§6.1 曲线应用行 ≤20 ms；超 20 ms 按 R14 阶梯处置，不自动放宽）。
9. **延迟按 `seq` 回填配对**，不得按时间就近；配对率与丢弃帧数**必须随报告给出**。
10. **不得引用历史数字**（39.69 dB / 7.1 s / 3562 的 255 ms）作依据或换算基础。

## 3. 板上执行纪律（规则 `30-board-safety.md` §4）

- 编译与运行在**演示板原生**进行（`ssh board` 免密；板上资产 `~/rknn_ab/`）。默认只做**只读探测**（节点枚举、`v4l2-ctl -L`、`lsmod`、容量查询）。
- **有副作用的操作**——取 DRM master 需 `sudo systemctl isolate multi-user.target`（关桌面）、停流、填满分区、改 systemd 单元——**执行前必须先说明影响面与恢复步骤并取得你确认**。恢复步骤：`sudo systemctl isolate graphical.target`。
- 故障注入类实验**一步一恢复**，禁止连续注入后一次性收拾。

## 6. 验证方式（端到端）

```
# 板上原生构建（零告警为通过条件之一）
cd /path/to/repo && cmake -S . -B build && cmake --build build -j4

# 扩展自检（签名 / ABI / 后缀 / 双精度一致性）
python3 -c "import realtime_apply; print(realtime_apply.__file__)"
python3 tools/bench.py apply-micro --impl native --shape 512x288 --precision fp16

# 链路场景（需 DRM master：先 isolate multi-user.target，结束 restore graphical.target）
python3 tools/bench.py --scenario realtime --breakdown --baseline
python3 tools/bench.py --scenario step-response
python3 tools/bench.py --validate-report <report.json>

# 离线数值对账（与探针逐位比对，不需要 DRM master）
python3 tools/bench.py curve-diff-fp16 ...
```

**通过判据**：① 构建零告警；② `import realtime_apply` 成功且签名与 §5 C 节逐字一致；③ U8 / FP16 两档数值一致性检查通过；④ NEON 与标量逐位一致；⑤ `bench.py --scenario realtime` 报告可生成（**指标达标与否按 §13 另判**，且**空链路基线须由 M1 给出**）；⑥ §11.2 M2 ①②③ 全过。
