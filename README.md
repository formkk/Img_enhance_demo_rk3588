# RK3588 极暗光增强实时演示系统

在单块 RK3588 板上，把「**极暗光视频 → 看得清的画面 → 传得动的码流 → 机器读得懂的检测结果**」跑成一条**不依赖 PC / 不依赖桌面**的实时演示链路。

---

## 这是什么

系统面向约 1 Lux 的暗光现场：相机输出的 1080p 画面先在板端做实时增强并双屏显示；需要更高画质时触发一次高画质增强；需要展示带宽与机器可用性时，再把增强结果压成真实码流、解码重建并跑一次目标检测。

整条链路只用一个进程（`main.py`）+ 一个 systemd 单元托管，启动后自动进入演示画面。

## 三路能力

| 路 | 做什么 | 时延 / 帧率 | 操作入口 |
|---|---|---|---|
| **实时路** | 1080p 采集 → 低分辨率曲线估计 → 8 次迭代曲线映射（单遍融合）→ 双屏输出 | ≈15 FPS；屏上端到端 ≈40 ms | 上电即运行 |
| **HQ 路** | 触发后冻结取 8 帧做时域平均 → Retinexformer 单帧增强 → 全屏呈现 | 触发 → 全屏 ≈10 s（预算 45 s） | 底栏「高质量增强」键 |
| **DCM 路** | 增强图 → 深度压缩编码（真实码流）→ 熵解码重建 → 板端检测器叠框 | ≈8 s；码流 17–25 KB（压缩约 60–90×） | 底栏「DCM 特征检测」键 |

三路共用同一块 MIPI 画布；HDMI 为画布的整幅镜像，两屏画面一致。

## 硬件与环境

| 项 | 规格 |
|---|---|
| 板卡 | LubanCat-5 V2（RK3588，8 核 CPU + 6 TOPS NPU） |
| 相机 | IMX415（MIPI CSI，1080p） |
| 显示 | MIPI DSI 1024×600 + HDMI 1920×1080（镜像） |
| 系统 | Debian 11 / 内核 5.10.160 / aarch64 |
| 部署 | `deploy/starlight-demo.service`（`WantedBy=multi-user.target`） |

## 快速开始

板端（演示机）：

```bash
sudo systemctl start starlight-demo     # 启动演示（进入 RUN_DEMO）
sudo systemctl stop  starlight-demo     # 停止演示
journalctl -u starlight-demo -n 50      # 查看运行日志
```

开发机（构建与计量）：

```bash
python3 tools/bench.py --scenario realtime --rounds 3 --frames 300   # 实时路计量
python3 tools/bench.py --scenario hq --seq-log --runs 10             # HQ 触发计量
```

> 详细构建步骤见 [docs/build.md](docs/build.md)；对外使用方法见 [用户使用说明书](docs/用户使用说明书.md)。

## 目录导航

| 路径 | 内容 |
|---|---|
| 根级 `*.py` | 交付链路：五条执行流（采集 / 曲线估计 / 逐帧应用 / HQ 推理 / 双屏显示）+ OSD、指针输入 |
| `native/` | C/C++ 内核与 pybind 绑定：RGA、DRM、NPU 推理、曲线应用、OSD 原语、MFA |
| `models/` | ZDE++（实时路）与 Retinexformer（HQ 路）的 RKNN 模型 |
| `assets/` | 运行期只读资源（OSD 中文预渲染位图） |
| `deploy/` | systemd 单元、桌面图标、启动脚本 |
| `tools/` | 模型转换、探针、计量（`bench.py`）、评审与数据工具 |
| `docs/` | **主基准**、用户说明书、附件规范（build / logging / measurements）、设计档、阶段计划、证据档 |
| `review/` | 界面与评审产物；`review/presentation/` 放对外汇报材料 |
| `DTM/` | DCM 参考软件归档与实验脚本（C 层，非交付代码） |
| `hq_optimize/` | HQ 路优化任务目录（C 层，含离线采集素材） |
| `data/` | 人工标注数据集（仅标注文本入库，图片与原始包不入库） |
| `refs/` | 外部参考资料（不入库） |

## 关键约定

- **主基准是唯一 SSOT**：与本仓库其它文档冲突时，以主基准为准；任何技术裁定都必须回写主基准（正文 + §14 变更记录 + §15 开放项）。
- **文档三层**：规范（`docs/*.md`）→ 设计（`docs/design/`）→ 记录（`docs/plans/`、`docs/evidence/`），下层不得复制上层取值、不得自行裁定开放项。
- **运行期只允许曝光 / 增益微调**；其余 ISP 参数由启动时选定，改值须改配置后重启。
- **链路输出原样归档**：不对画面做 γ / 对比度 / 直方图等后处理后再当作依据。
