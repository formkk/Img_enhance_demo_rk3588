## 0. 通用约定

- **依据载体**：一律引用 `bench.py` 的 JSON 报告（字段清单见主基准 §6.5），**本表不重定义报告字段**；登记时只填报告文件路径与结论值。
- **测量条件随行记录**：板型、权重哈希（`model.zde_weight_hash` / `hq.model_id`）、曲线档、精度档、config 快照哈希；缺任一项视为未登记。
- **时钟口径**：`mono_ns`（`CLOCK_MONOTONIC`）唯一可用于时序比对；时间戳来源（`SOE`/`EOF`）须随行注明（主基准 §5 契约 A、§6.5）。
- **复检绑定**：M1 权重一经变更（含实拍域 fine-tune），按主基准 §11 的 O11 规则全量重跑，本表对应行同步复检。
