## 1. RGA 几何链路：实现参数（§11.1-2 前半）

### 1.1 目标几何（§3.1 G1 第 1 条）

```
src  1920×1080 NV12（wstride/hstride = 1920/1080）
  --improcess(srect={0,0,1920,1080}, drect={0,0,480,270}, IM_SYNC)-->  有效区 480×270 RGB888
  pad  第 0 行与第 271 行 = 零（缓冲初始化时一次性填充）
dst  480×272 RGB888（wstride/hstride = 480/272）
```

### 1.2 实测参数表

| 项 | 取值 | 依据 |
|---|---|---|
| 缓冲来源 | `open("/dev/dma_heap/system-dma32")` + `DMA_HEAP_IOCTL_ALLOC` + `mmap` | 生产链路 §3.3「采集 1080p NV12 (DMABUF)」；且低 4G 内存规避 `rga_mm: RGA_MMU unsupported memory larger than 4G` |
| 包装方式 | `wrapbuffer_virtualaddr_t(base + 480*3*1, 480, 270, 480, 272, RK_FORMAT_RGB_888)`（**偏移基址子视图**） | 见 §1.3 |
| blit | `improcess(src, dst_eff, pat=0, srect={0,0,1920,1080}, drect={0,0,480,270}, prect={0,0,0,0}, IM_SYNC)` | 一次调用同时完成 scale + CSC |
| pad 填充 | `improcess(zero_full, dst_full, pat=0, {0,0,480,2}, {0,0,480,2}, …, IM_SYNC)` + `{0,270,480,2}`（**2 行**，重叠行被随后的 blit 覆盖） | RGA 不接受高度 <2 的矩形 |
| 分核 | `imconfig(IM_CONFIG_SCHEDULER_CORE, 3)`（= `IM_SCHEDULER_RGA3_CORE0 \| CORE1`） | §1.4；注意 `mask=0` 被库拒绝（`IM_STATUS_ILLEGAL_PARAM`），故"不干预"= 不调用 |

### 1.3 两条平台硬约束（实测）

| 约束 | 实测 | 后果 |
|---|---|---|
| **`drect` 的 y 偏移必须偶对齐** | `drect={0,1,480,270}` → `-3`「Hardware limitation dst rect, unsupported operation of images smaller than 2 pixels」；`{0,2,…}` → 成功；`{0,4,…}` → 越界报错（因 4+270 > 272）。**VA 与 fd 路径表现完全一致** | 「上下各 1 行 pad」的 dy=1 布局**不能用 drect 表达**，只能用偏移基址子视图（drect dy=0） |
| **`imfill`（colorfill）对 RGB888 不可用** | `imfill_t(dst, {0,0,480,2}, 0, 1)` 与整块填充**均返回 `IM_STATUS_FAILED`**；驱动侧 `RgaCollorFill: RGA_COLORFILL fail: Invalid argument` + `rga_mm: failed to map buffer` | 零填充只能靠 `improcess` 从零源块拷入；§3.1 G1 原表述「由 RGA 的 letterbox/背景填充**在一次 blit 内完成，不额外拷贝**」**在本平台不可实现** → **已于 v3.27 裁定 O32 = 方案 (a) 修订措辞**（见下方"裁定结果"） |

**⇒ 裁定结果（v3.27，§15 O32 = 方案 (a)「认可替代实现、修订措辞」）**：

1. **§3.1 G1 第 1 条改为**：pad 在**缓冲池初始化时**由 RGA 以 `improcess` 从零源块拷入（每缓冲各一次，实测 **0.45 ms/缓冲**），**每帧只做一次 scale+CSC blit**（实测 **2.10 ms** 中位）；该 blit **不越写 pad 行**（哨兵验证）⇒ **每帧无额外拷贝**。原「在一次 blit 内完成」的**表述删除**——条款**目的**由替代实现**完整满足**。
2. **§10.4 `pipeline.curve_geometry` 行同步修订。**
3. **候选优化点 (b)（登记备查、非达标项）**：改用 legacy `c_RkRgaBlit` 的 `rga_info_t` 背景色/**裁剪**字段、C++ `improcess` 的 `im_opt_t.color`（probe 输出中可见 `rga_dump_opt: color[...]`），或**升级 librga 后重探**。**目标是省掉零源缓冲与初始化路径，收益属实现简洁性而非性能**（现状已是每帧零成本），故**不列 M0/M2 达标项**；**复探触发条件 = librga 版本升级**。

**为什么不构成每帧代价**：blit 的写入范围 = drect，实测 pad 行**不被触碰**（`pad_method=none` 时哨兵 0xAA 完整保留）。故 pad 只需在**缓冲池初始化**时按缓冲各填一次；双/三缓冲池 = N 次 0.45 ms，**摊销到每帧为 0**。这一实现选择的净效果与契约条款的目的（避免每帧额外拷贝）一致。

### 1.4 时序与分核（安静板，200 次 ×3 组，dark 1080p NV12 输入）

| 配置 | blit 中位 | blit p90 | pad 一次性 | 每帧路径（fill+blit，仅对照） |
|---|---|---|---|---|
| mask=0（不调用 imconfig） | 2.103 ms | 2.138 | 0.44 | 2.31 |
| mask=1（CORE0） | 2.102 | 2.138 | 0.48 | 2.31 |
| **mask=2（CORE1）** | **2.053** | 2.087 | 0.26 | 2.24 |
| mask=3（CORE0\|CORE1） | 2.102 | 2.132 | 0.48 | 2.31 |
| 双 job（mask=3，同步提交） | 2.101（单） | — | — | **4.03（批）** |
| 双 job（mask=3，`IM_ASYNC` 提交） | 2.104（单） | — | — | null（A 线程提交返回非 SUCCESS） |

- **§6.1 的「RGA 含排队 ≤6 ms」**：本项只覆盖 1080p→480×270 这一次 blit（**2.10 ms**）；链路内其余 RGA 算子（1080×608 缩窗 ×2、MIPI 画布合成）**未在本轮实测**，M0-13 不作合计判定。
- **分核结论**：库默认（`IM_SCHEDULER_RGA3_DEFAULT = CORE0`）等价于只用一核。取 **mask=3** 的理由是给 M2 的 HQ 触发路径与实时链路的 RGA 并发留第二个核（单 job 无代价）；实测 mask=2 略快 2.4%（2.05 ms），但 0.05 ms 不足以换取放弃调度自由度。
- **并行性未证实**：同步提交的双 job 耗时 = 2× 单 job；`IM_ASYNC` 经 7 参 C 形态 `improcess` 被拒（该形态无 `release_fence_fd` 出参，需 C++ 重载）。⇒ 若 M2 需要 RGA 真并发，须在 **M0-6 并发压测**中用 C++ 形态重验。

### 1.5 输出正确性校验

| 校验 | 结果 |
|---|---|
| pad 行 | 三个输入帧（图案/相机/暗帧）的 `pad_row_top_nonzero` / `bot_nonzero` **均为 0** |
| blit 写入范围 | `pad_method=none` 时 pad 行哨兵（0xAA）完整保留 ⇒ blit **不越写** |
| 图案几何 | 四角色块精确落位：左上 **(254,0,0)** / 右上 **(0,254,0)** / 左下 **(0,0,254)** / 右下 **(255,255,255)**；白边 (254,254,254) |
| 缩放假象 | 水平 R ramp（179 步）与垂直 G ramp（179 步）**严格非降**（负步长数 = 0） |
| CSC 一致性 | 有效区 PSNR vs numpy BT.601-limited + BOX 参考：图案 **31.15 dB** / 相机帧 **36.99 dB** / 暗帧 **38.19 dB**（差值来自 RGA 缩放滤波器与 BOX 平均的差异，非几何错位） |

## 2. 黑带对边缘行的影响（§11.1-2 后半）

**方法**：以**pad 行的取值**做消融——同一张 RGA 输出的 480×272 底图，仅替换第 0/271 行：
`pad0`（契约：零）/ `pad_edge`（复制相邻有效行）/ `pad_gray`（128 中灰）。
三份输入以同一 INT8 480×272 模型（`zde_curve_480x272_int8_tk232.rknn`，u8 NHWC 喂入）推理，逐元素比较**已裁掉 pad 行的有效区**曲线场。

### 2.1 曲线场（场域）

| 对照 | 全有效区 mean / max | 贴 pad 上 8 行 mean / max | 贴 pad 下 8 行 mean / max | **内部（行 9..262）** |
|---|---|---|---|---|
| pad0 vs pad_edge | 0.00020 / 0.02496 | 0.00355 / 0.01386 | 0.00304 / 0.02496 | **0.00000 / 0.00000** |
| pad0 vs pad_gray | 0.00092 / 0.04298 | 0.01707 / 0.04298 | 0.01404 / 0.03605 | **0.00000 / 0.00000** |

逐行 profile（pad0 vs pad_edge，有效区第 1..12 行的 mean）：
`0.0065 0.0043 0.0044 0.0043 0.0038 0.0034 0.0017 0.0000 0.0000 0.0000 …`
⇒ 衰减半径 **恰好 7 行** = 模型感受野半径（7×(3×3)）。**第 8 行起逐元素差恒为 0**，是感受野的必然结果而非数值噪声。

### 2.2 图像域（1080×608 窗域，同一曲线做 8 iter 应用后）

| 对照 | 全窗峰值 | 上边界带 | 下边界带 | 内部 |
|---|---|---|---|---|
| pad0 vs pad_edge | **10.5 LSB** | 最外 17 行，max 6.8 / mean 1.23 LSB | 最外 16 行，max 10.5 / mean 0.88 LSB | **0.0 LSB** |
| pad0 vs pad_gray | **20.0 LSB** | 最外 17 行，max 20.0 / mean 5.48 LSB | 最外 17 行，max 15.6 / mean 3.24 LSB | **0.0 LSB** |

影响深度 16–17 窗行 = 7 场行 × 2.252（608/270），与场域结论自洽。

### 2.3 判定

1. 零填充的后果**有界且局部**：只在最外 7 场行 / 16–17 窗行，峰值 ≤10.5 LSB（与"边缘复制"相比）；内部恒为 0。
2. 峰值点位于曲线场量级 2.5e-2~4.3e-2，**高于** INT8 自身噪声（1.5e-2~1.7e-2），但**按行平均**只有 3e-3~1.7e-2，**低于**噪声。
3. **该边缘效应是感受野固有**：任何 pad 取值都无法消除，只能改变其幅度 2 倍以内 ⇒ **契约的零填充是最优或近最优选择，予以确认**。
4. **不触发 M0-8 §8.3 的量化陷阱**：本模型 `mean=[0,0,0] / std=[255,255,255]`（`docs/evidence/reports/M0-2/build_B_tk232.json`），uint8 `0` 反量化后**恰为实值 0.0**，与模型自身 conv padding 语义一致。

## 3. 8 iter 单遍融合（§11.1-13）

**实现**：`tools/apply_probe.c`。契约要点落到实处——载入一次、**寄存器内迭代 8 次**、写回一次；曲线场**双线性采样融合在同一循环内**，**不生成独立上采样曲线图**；采样按目标像素中心 `(i+0.5)/N` 归一化取 `u*CW − 0.5`，边界 clamp；采样表（每列/每行的 `i0, w`）预生成。

### 3.1 数值一致性（融合本身是否正确）

| 对照 | 结果 |
|---|---|
| NEON 单遍融合 vs 标量单遍融合（同一公式） | **mismatch_bytes = 0 / max_abs_delta = 0**（1,969,920 字节全等） |

### 3.2 DDR 流量核算（按代码结构逐项累加，@1080×608 = 1,969,920 B/帧）

| 实现 | 字节/帧 | @30 fps | 与 §3.3 基准值 |
|---|---|---|---|
| **单遍融合**（读 x 一次 + 写 y 一次） | 3,939,840（3.94 MB） | **118.2 MB/s** | 基准写 **≈118 MB/s** ✅ |
| 未融合（8 次迭代各读+写整幅一遍） | 31,518,720（31.5 MB） | **945.6 MB/s** | 基准写 **≈946 MB/s** ✅ |
| 比 | — | **8.0×** | — |

⇒ **§3.3 的 118 / 946 两个数字由本实现的结构精确复现**；"未融合即判未达标"这一执法判据成立。

### 3.3 耗时（30 次中位，CLOCK_MONOTONIC，`gcc -O3 -mcpu=cortex-a76`）

| iters | 标量 | **NEON** | 未融合（对照） |
|---|---|---|---|
| 1 | 17.35 ms | **12.10** | 23.03 |
| 2 | 19.17 | 12.93 | 25.06 |
| 4 | 24.79 | 14.62 | 27.07 |
| **8（契约）** | 39.16 | **17.81** | 31.07 |

**成本拆解**：

| 分项 | NEON 路径 | 占比 |
|---|---|---|
| 采样 + 载入/写回 + u8→f32 转换（iters=1 即全部发生） | **12.10 ms** | **68%** |
| 8 次迭代本体 | 5.71 ms（边际 **0.71 ms/iter**） | 32% |

**对标 §6.1**：目标值 **≤2 ms**，实测 **17.81 ms** ⇒ **超 8.9×**。
即使把迭代降到 2 次仍是 12.93 ms（≈6.5×）；**瓶颈是逐像素双线性采样（gather）而非迭代**。
float32 NEON 下 8 次迭代的理论下限 ≈ 656,640 px × 72 flop/px ÷ (2 op/cycle × 2.2 GHz) ≈ **11 ms**，故 **≤2 ms 在 float32 单核下不可达**。

**⇒ 裁定结果（v3.26，§15 O33 = 方案 1「按实测重排 §6.1 预算」）**：

| 项 | 重排前 | 重排后 |
|---|---|---|
| 曲线应用 @1080×608 ×8 iter | ≤2 ms（目标值，偏紧） | **≤20 ms**（= 实测基线 + ~2 ms 余量） |
| 帧路径合计（6 + 应用 + 6） | ≤14 ms | **≤32 ms** |

- **不放松任何验收项**：约束源是 §13 的 **MIPI 双窗 P50 ≥25 FPS（无 HQ）/ ≥20 FPS（HQ）** 与端到端 **P95 ≤80 ms**；§6.1 本身不含 ms 级验收指标。≤32 ms 落在 30 Hz 周期（33.3 ms）内，对 25 FPS（40 ms 周期）余量 **8 ms**。**§13 未改动**。
- **定性**：原 ≤2 ms 是**估计错误而非实现退化**——本节的单遍融合与 DDR 流量两项**均已达契约**，被证伪的只是那个 ms 目标值。
- **防退化**：M2 交付的 `realtime_apply` 不得劣于 M0 基线 **17.81 ms**；超 20 ms 按 §12 的 R14 阶梯处置。**LUT 折叠 / fp16 算术 / 多核拆分列为 M2 可选优化（非达标必需）**。

### 3.4 复现命令

```bash
# ① RGA：生产口径（dma-buf + 偏移基址子视图）
ssh board 'cd ~/rknn_ab/probe && \
  ./rga_probe ~/rknn_ab/data/dark_1080p_nv12.raw 1920 1080 480 272 200 3 fdva system-dma32 sync \
      - /tmp/r_fdva.json'
# ② 黑带消融：RGA 输出 → INT8 480×272 → 曲线场（pad0 / pad_edge / pad_gray 三份输入）
ssh board 'cd ~/rknn_ab/probe && \
  ./rknn_c_probe ~/rknn_ab/models/zde_curve_480x272_int8_tk232.rknn \
      ~/rknn_ab/data/est_pad0_nhwc.f32 20 nhwc float nosram u8 noperf /tmp/c_pad0.f32 0'
# ③ 曲线应用：单遍融合
ssh board 'cd ~/rknn_ab/probe && gcc -O3 -mcpu=cortex-a76 -o apply_probe apply_probe.c -lm && \
  ./apply_probe ~/rknn_ab/data/apply_in_1080x608.rgb 1080 608 \
      ~/rknn_ab/data/curve_eff_480x270.f32 480 270 30 fused_neon /tmp/apply_out.rgb 8'
```

| 项 | 归属 |
