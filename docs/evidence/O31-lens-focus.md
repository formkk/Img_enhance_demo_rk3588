## 1. 目的（O31 三项）

O31 = **摄像头镜头定型与对焦达标**（v3.24 由现场镜头换装派生，**阻塞 M1 前置**）。三项：① 保留哪一枚镜头；② 对焦达标的判据；③ 换镜头后 IQ（lens shading / 锐化 / CCM）不匹配的处置。

## 2. 结论

| # | 项 | 结论 |
|---|---|---|
| ① | 镜头定型 | **保留 8 mm 可调焦**（用户 2026-09-18 确认；原 120° 广角不采用） |
| ② | 对焦达标 | **用户现场调焦并确认「已是最清晰状态」**；实测焦环位于峰值（见 §4） |
| ③ | IQ 失配处置 | **并入 §9.5 的 M1 ISP 调参**（不单独立项；换镜头后的 shading/锐化/CCM 随 M1 统一重标） |

**残留（不在 O31 三项内）**：**安装朝向倾斜仍未处理**（§11.1-1 的 M1 前置闸口含"摆正"）——本轮实测画面竖直结构仍斜置。

## 3. 方法（口径与复现）

| 项 | 设置 |
|---|---|
| 采集 | `/dev/video11`（rkisp mainpath）1920×1080 NV12 |
| 指标 | **中心 1:1 480×270 的 GRAY8 Laplacian 方差**（`cv2.Laplacian(g, CV_32F).var()`）——与 `environment/board-lubancat5.md` §8.2 的 v3.24 同口径 |
| 靶标 | 用户指定：**约 2.6 m 处室内实物**（中等纹理；非印刷靶标） |
| 采样 | 静置 12 帧 @0.5 s；扫焦 20 帧 @1 s |

```bash
# 预览 + 指标通道（tee：一路出画面，一路裁中心 1:1 480x270 GRAY8 落盘）
ssh board 'export DISPLAY=:0 XAUTHORITY=/run/user/1000/gdm/Xauthority; xset s off -dpms; \
  mkdir -p /tmp/live; setsid nohup gst-launch-1.0 -q v4l2src device=/dev/video11 \
  ! video/x-raw,format=NV12,width=1920,height=1080 ! tee name=t \
  t. ! queue ! videoscale ! video/x-raw,width=1024,height=576 ! videoconvert ! ximagesink \
  t. ! queue ! videocrop top=405 left=720 right=720 bottom=405 ! videoconvert \
  ! video/x-raw,format=GRAY8 ! multifilesink location=/tmp/live/c_%05d.raw max-files=2 \
  > /tmp/gst_disp.log 2>&1 </dev/null &'
# 取最新一帧算指标（本地 cv2）
ssh board 'cp $(ls -t /tmp/live/c_*.raw | head -1) /tmp/live/pick.raw'
```

## 4. 实测

### 4.1 静置（对焦后 12 帧 @0.5 s）

| 统计 | 值 |
|---|---|
| 中心 1:1 480×270 Laplacian 方差 | **mean 32.6 / min 31.7 / max 33.4**（极稳） |
| 场景 | mean 67.0 / std 25.3 / p1–p99 = 15–144 |

### 4.2 扫焦（20 帧 @1 s）

| 阶段 | 帧 | Laplacian 方差 |
|---|---|---|
| 未动（原对焦位置） | 1–7 | 31.8 → 32.3 → 32.5 → 33.0 → 31.7 → 32.3 → **33.7** |
| 拧离焦后 | 8–20 | 22.7 → 10.1 → 8.9 → 11.3 → 8.6 → 6.7 → 6.7 → 7.8 → 6.6 → 12.7 → **5.2** → 6.4 → 6.1 |

**峰值 33.7（第 7 帧 = 原对焦位置）/ 最低 5.2 ⇒ 峰值÷离焦 = 6.46×**。
⇒ 焦环位于实测峰值；**扫焦仅覆盖单侧**（从原位往一个方向拧到底），反方向未扫。

### 4.3 中心 1:1 图

`docs/evidence/reports/O31/center_1to1_480x270.png`（原始 GRAY8 见同名 `.raw`，不入库）：可见真实室内物体（椅/金属架、深色台面），中等纹理；**画面竖直结构斜置**。

## 5. 判据讨论（供后续复检）

1. **实物靶标的指标强依赖场景纹理**，v3.24 的"合焦通常 >150"是**同类桌面场景的经验值**，与实物场景不可直接比 ⇒ 本轮**不以绝对阈值判"达标"**，而以「焦环位于峰值 + 用户目视确认」为准。
2. **绝对量级偏低（33.7）**：未排除「8 mm 镜头在 2.6 m 处本身偏软」或「目标纹理不足」两种可能。**若日后需要可复现的绝对阈值**，须换**高纹理靶标**（如 2.6 m 处印刷文字）另测并登记。
3. **扫焦只覆盖单侧** ⇒ 峰值"有界性"仅一半证据；如需完整曲线，须从峰值往反方向补扫。

## 8. 附：本轮顺带记录的两个板端坑（非 O31 内容）

1. **面板被 DPMS 熄灭 ⇒ 黑屏无背光**：`/sys/class/backlight/backlight-dsi0/bl_power` 被置 **4**（`FB_BLANK_POWERDOWN`），而 `brightness` 仍 200 ⇒ 表现为"黑屏无背光"。恢复 = `echo 0 > /sys/class/backlight/backlight-dsi0/bl_power`；预防 = 开发期 `xset s off -dpms`。**演示态（`multi-user.target`，无桌面）不适用**。
2. **`cam_preview.py`（HTTP+JPEG 管线）长跑后流会停**（`/stat` 的 `seq` 卡住，两次快照 md5 相同；摄像头本身健康）⇒ 长时间预览改用**直接 gst 窗口 sink**。
   ⚠️ **更正（同日实测）**：最初用的 `v4l2src ! tee`（一路出画面、一路裁图测量）**会引入明显鬼影**——两路共享 v4l2 的 DMA 缓冲，测量支路拖住缓冲使画面拿到被复写的帧。⇒ **预览必须单路**；测量须与预览**分时**做，不得 tee。

## 9. 记录：预览「拖影」的根因 = ISP 时域降噪（3DNR）（2026-09-18，**只记录、未改动**）

用户报告预览画面**拖影持续 >1 秒**；去掉 tee 改单路后**依旧** ⇒ **排除预览管线**。

| 项 | 事实 |
|---|---|
| IQ 文件 | `/etc/iqfiles/imx415_CMK-OT2022-PX1_IR0147-50IRC-8M-F20.json` |
| **文件对应镜头 ≠ 实装镜头** | 文件按 **CMK-OT2022-PX1 / IR0147-50IRC / 8M / F20** 调优；实装为 **8 mm 可调焦** ⇒ **IQ 调优与镜头不匹配** |
| 时域降噪段 | **`bayertnr_v2`**（Bayer 时域 NR）；另有 `bayer2dnr_v2` / `cnr_v2` / `ynr_adjust_*` |
| 驱动侧可调性 | `/dev/video11` **无 NR 控制项**（仅 `pixel_rate`）⇒ 只能在 IQ JSON 里改，改后须重启 `rkaiq_3A_server`（pid 393） |

**判定**：>1 s 的拖影 = **时域累积**（`bayertnr_v2` 在暗光下强度拉高），**不在预览管线上**。
**处置（用户 2026-09-18 指示）**：**只记录、本轮不改动**（关掉时域 NR 会使暗部噪点明显增加）。该事实并入 **§15 的 O40（3DNR 采集期与运行期一致性）** 与 **O31③（IQ 失配 → §9.5 的 M1 ISP 调参）**。
