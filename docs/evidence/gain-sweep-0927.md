## 2. 核心结果

| 增益 | 臂 | 全图灰度均值 | 暗块均值 | 暗块 σ 中位 | **提亮倍数** | **噪声放大倍数** |
|---|---|---|---|---|---|---|
| **12×**（reg 72） | 原图 ISP | 5.22 | 0.94 | 1.79 | 1.00× | 1.00× |
| | 实时路 ZDE++ | 35.53 | 8.16 | 13.40 | 6.81× | **7.50×** |
| | HQ v1 | 65.59 | 26.25 | 17.53 | 12.31× | **9.58×** |
| **16×**（reg 80） | 原图 ISP | 8.36 | 1.79 | 1.94 | 1.00× | 1.00× |
| | 实时路 ZDE++ | 50.98 | 14.71 | 14.21 | 6.10× | **7.33×** |
| | HQ v1 | 62.90 | 34.86 | 11.57 | 7.43× | **5.48×** |
| **20×**（reg 87） | 原图 ISP | 9.56 | 2.40 | 2.33 | 1.00× | 1.00× |
| | 实时路 ZDE++ | 56.56 | 19.58 | 16.66 | 5.92× | **7.16×** |
| | HQ v1 | 62.56 | 36.01 | 11.92 | 6.47× | **5.03×** |

> 实时路与 ISP@960×540 同网格（960×540）比较；HQ 亦为 960×540；提亮/噪声倍数均对同网格原图。

### 2.1 三条可读结论

1. **HQ 路：12× 明显最差，16× 与 20× 基本持平、20× 略优。**
   噪声放大 **9.58× → 5.48× → 5.03×**（16× 比 12× 降 **43 %**）；暗部 σ 17.53 → 11.57 → 11.92。
   **机理**：12× 时原图太暗（暗块均值仅 0.94），HQ 必须提亮 **12.3×** 才能到 ~66；16×/20× 只需 7.4× / 6.5× ⇒ **提亮需求小则噪声放大也小**。
   三臂**输出亮度几乎相同**（65.6 / 62.9 / 62.6）——网络把输出钉住在 ~63–66，因此**画质差异全部落在噪声上**。

2. **实时路：三臂几乎无差别**，噪声放大 **7.50 / 7.33 / 7.16×**（极差 ≤0.35）。
   但输出亮度随增益明显变化（**35.5 → 51.0 → 56.6**）⇒ **实时路对输入亮度不做归一**，输入暗则输出暗；暗部 σ 反而随增益升高（13.4 → 14.2 → 16.7）。

3. **原图本身**：随增益升高，亮度 5.22 → 9.56（×1.83）、暗部 σ 1.79 → 2.33（×1.30）⇒ 原图暗部「均值/σ」比为 **2.92 → 4.31 → 4.10**（16× 达峰、20× 略降）。

### 2.2 与 §15 O87 的关系（**口径不同，不得并列**）

O87 曾实测「固定曝光下**增益越高 SNR 越差**（9/9 点单调下降）」⇒ 方向是**低增益更优**。本轮在 **0.75 Lux**（落在 O87 的 0.2 / 1 / 4 Lux 邻域内）看到的是：**两路推理图侧都是 12× 最差、20× 最好**，与原图侧的 16× 达峰并不一致。
⚠️ 两者**口径不同**（O87 = 暗部块均值 / **时域** σ_eff；本轮 = 暗部块均值 / **空域** σ 中位含块内结构）⇒ **只登记事实与差异，不作合并结论**。

|---|---|---|
| F / G（2026-09-25 03:01） | 0.55 Lux | **23.09 / 22.48** |
| 本轮（2026-09-28 00:02，reg 87 档） | 0.75 Lux（更正后） | **10.01** |

- 两次采集**画的是同一台面、同一机位**（画面内容一致，可从 `reports/gain-sweep-0927/A_g087.png` 与 `reports/site-compare-0924/f/A_exp8879.png` 直接比对）。
- **标签**说照度升了 1.36×（0.55 → 0.75），**实测**却显示亮度**降了 2.3×**（22.8 → 10.0）⇒ **方向相反**。
- 结论：**至少一个环节不可控**（照度口头值不准 / 期间动过镜头变焦或光圈 / 灯的实际输出变化），
  ⇒ **两次会话的数字不得互相换算或并列**；照度必须靠**照度计实测**才能作为随行条件（见 §15 **O147(b)**、**O148(e)**）。
- 本轮**内部**三臂是可比的（同一窗口内背靠背采集，Y 均值 5.49 / 8.62 / 10.01 单调随增益上升）。

### 2.4 ⭐ 多帧时域平均（输入侧）—— **负结果：在演示档（3DNR 开）下无效**

**动机**（用户 2026-09-28「探索提高 HQ 输出质量的办法，例如取多帧」）：O87 曾实测「多帧平均按 √N 有效」（1 Lux、采集档 3DNR 关、N=4 ⇒ SNR 3.92）。
**做法**：在**送网络之前**把 N 帧在 RGB 域平均（帧窗 `[8, 8+N)`，float64 累加），再送 HQ —— 网络只跑 1 次。
（**输出侧平均不可行**：HQ 单帧 ~10 s ⇒ ×N。）

| 增益 | N | ISP@960×540 暗块 σ | **HQ 暗块 σ** | HQ 噪声放大倍数 |
|---|---|---|---|---|
| **12×** | 1 | 1.246 | 3.665 | 2.942 |
| | 2 | 1.228 | 3.888 | 3.165 |
| | 4 | 1.211 | 4.223 | 3.486 |
| | 8 | 1.177 | **4.958** | **4.211** |
| **16×** | 1 | 1.986 | 6.689 | 3.369 |
| | 8 | 1.938 | 6.639 | 3.426 |
| **20×** | 1 | 2.071 | 4.864 | 2.349 |
| | 8 | 2.053 | **5.386** | 2.623 |

**结果**：**多帧平均没有把 HQ 噪声压下来，12× 档反而 +35 %**（3.665 → 4.958）。

**根因（已实测钉死）** —— 时域 σ_eff vs 空域 σ（Y 域、暗块像元集、O87 同口径）：

| 增益 | 时域 σ_eff | 空域 σ 中位 | **时域 / 空域** |
|---|---|---|---|
| 12× | 0.848 | 1.882 | **0.451** |
| 16× | 0.997 | 2.076 | **0.480** |
| 20× | 1.388 | 2.530 | **0.549** |

⇒ **只有约一半的暗部噪声是时域随机的，另一半是空域固定图案 / 结构**。设 σ² = σ_t² + σ_f²，
则 N 帧平均的理论极限 = `σ·√(1 − 0.451²) = 0.893σ`（12×，即**最多降 10.7 %**）；N=8 时为 `0.907σ`（**降 9.3 %**）。
⇒ 实测 ISP 侧 N=1→8 只降 **5.5 %**，与理论极限同量级；而 HQ 侧因平均后输入略暗（ISP@960 均值 6.98 → 6.31）
令网络施加更陡的曲线，**放大收益反被抵消 ⇒ 净变差**。

**机理**：演示档 IQ 的 **3DNR 开着**，ISP 已把时域随机噪声压掉大半 ⇒ **连续帧高度相关，多帧平均近乎无效**。
这与 O87「多帧平均有效」**不矛盾** —— O87 用的是**采集档（3DNR 关）**，帧间独立。

**结论**：**在当前演示 IQ（3DNR 开）下，多帧平均这条路封死**；要让它重新有效，须改用采集档（3DNR 关）
——那会改变交付链路的输入域，属契约变更（见 §15 **O149**）。

## 3. 效力边界

1. **非验收依据**；不改任何已裁取值、`config.yaml` 零改动、无板端代码改动、无权重改动。
2. **结论只适用 0.75 Lux**——该照度**恰落在 O87 的 1 Lux 硬目标邻域内**（**用户 2026-09-28 更正：原登记误记 0.05 Lux**）；原图三臂仍偏暗（全图均值 5.2 / 8.4 / 9.6），但已非「极端下限」。
3. **无 GT ⇒ 只比亮度与噪声**，不含 PSNR / SSIM 等画质指标；**「数值对比」不能读作画质优劣**。
4. 样本面窄：**单机位 / 单照度 / 每档单帧（第 25 帧）/ 单次采集**，照度为**用户口头值、未用照度计**；镜头变焦环位置未记。
5. **不得据本档变更 `isp.presets.*.gain`**——增益预设定稿属 §10.4，变更须走 §15 裁定并回写 §10.4 / §14 / §9.5。
