⇒ **⚠️ 性质差异（须随行）** —— **B 不是"纯曝光阶梯"**：曝光在变（2 s → 1/15 s = **30×**）**且 ISO 在变**（long 侧 auto 500–2500 vs short 侧固定 6400，**4–8×**）⇒ 其 `low→normal` 映射**耦合了增益变化**，与 A / `photo_3rd` 的"仅快门变"**不是同一类协议**。

**③ 档位标号方向的核验** —— `low1 > low2 > low3` 的**亮度单调**（§3.4.1 ③）与**曝光单调**（A：0.06667 > 0.03333 > 0.01667；B 同值）**同向** ⇒ **映射成立**：`low1` = 三档中最长曝光、`low3` = 最短。
> **⚠️ 判定强度（如实登记）** —— A 批为**目录级显式对应**（`short1/2/3` 三目录各自曝光恒定，实测得到）；B 批为**同目录内含三档曝光**（0.01667/0.03333/0.06667），其 `low1/2/3` 标号**按"亮度单调 ⇔ 曝光单调"推定**（与 A 同构），**未逐对核验 processed PNG 与具体 CR3 的字节级对应**。

**④ 对 O140 的意义（本节为取值依据，不代裁定）** —— **"低档有效像素极少"（§3.4.1 ④）与"欠曝倍数"直接相关**：A 的 `low3` = **240×** ⇒ 像素 >8/255 占比 0.00%；B 的 `low3` 中位 = **23.43×** ⇒ 同样 0.00%（边缘），而 B 的 `low1` = **5.86×** ⇒ **0.26%**（最好的一档）。⇒ **判据可按"欠曝倍数"或"有效像素占比"两条路给出，二者取值待裁**。

**⑤ 未取到项（如实登记）** —— **`FNumber` 未取到**（`CMT2` 内无 `0x829D`）；B 批 `read.me` 自记 **f=2.8**、A 批**未记光圈**。

### 3.4.3 两批次的「运动拖影审组」（**v3.86 追加 83，2026-09-23 执行**）+ **判据移植失败登记**

**动机** —— 按 O140 的关联要求，把 `photo_3rd` 已建立的三判据（`rel_p95` / `top1_share` / `grad_ratio`，**O137c 已裁定**）**移植到这两批**。

**① ⚠️ 移植失败（结论：判据不适用，不判为"处处拖影"）**

| 现象 | 实测 |
|---|---|
| 掩码污染 | 首版掩码门限取线性域 `low > 1e-9`，**等价于 8-bit 的 0.04** ⇒ **把 1 LSB 的量化噪声全部纳入**（该批低档大多像素本身就是 0–1 LSB） |
| 标定 k 被放大 | 最小二乘标定 `k` 中位 = **A 165 / 329 / 494**、**B 10.5 / 21.1 / 43.3**，而**标称等效比**仅 **60 / 120 / 240×**（A）与 **5.86 / 11.72 / 23.43×**（B）⇒ k 约为标称的 **2.7× / 1.8×**（**被量化噪声抬高**） |
| 指标全退化 | `rel_med` ≈ **0.9989–0.9996**、`rel_p95` ≈ **1.0000**（A）/ **4.3–13702**（B）、`top1_share` **0.61–0.80**（A）/ **0.99**（B） |
| 触发结果 | **SUSPECT 26–29 / 29**（A）、**28 / 28**（B）⇒ **100% 触发** |

⇒ **`rel_p95 ≈ 1.0` 的含义是"两帧不相关"，而非"运动"**；其成因是低档帧在该掩码下几乎全是量化噪声。**本档据此判定：三判据法不可移植到 8-bit sRGB 近黑配对**（该判定本身即为本次产出之一）。

**② 对症指标（改写为"高光窗局部锐度"，避开量化污染）**

**口径** —— 取低档帧**最亮像素**为中心的 **192×192 窗**（**原分辨率 6024×4020，不重采样**）；各窗**按自身 99.9 分位归一**（消去曝光差）；`sharp() = 梯度幅值的 99 分位`；`sharp_ratio = sharp(Normal)/sharp(Low)`（**<1 ⇒ 亮帧更糊 ⇒ 拖影**）。

| 批次 / 档 | `sharp_ratio` 中位 [范围] | 高光窗 NCC 中位 [范围] | 可测场景数（窗内 L≥32 像素 ≥30） |
|---|---|---|---|
| A `low1` | **1.585** [0.386, 10.22] | 0.526 [0.328, 0.942] | **24 / 29** |
| A `low2` | **1.637** [0.059, 5.96] | 0.437 [0.211, 0.880] | **19 / 29** |
| A `low3` | **1.849** [0.142, 1.2e8†] | 0.334 [0.014, 0.767] | **8 / 29** |
| B `low1` | **1.087** [0.181, 2.39] | 0.811 [0.606, 0.975] | **25 / 28** |
| B `low2` | **1.016** [0.128, 3.15] | 0.705 [0.440, 0.961] | **24 / 28** |
| B `low3` | **1.167** [0.103, 4.63] | 0.622 [0.298, 0.856] | **21 / 28** |

† 分母退化伪值（低档窗内梯度 ≈ 量化台阶）⇒ **该单个极值不作结论**。

**③ 两条结论（限定范围，不越界）** —— **(a) 未发现运动拖影证据** —— `sharp_ratio` 中位 **均 > 1**（A 1.59 / 1.64 / 1.85；B 1.09 / 1.02 / 1.17）⇒ **亮帧不系统性更模糊**；与 `photo_3rd` 的 `grad_ratio` 中位 1.051 ≈ 1 的"拖影非系统性问题"**方向一致**。**(b) 但高光窗 NCC 偏低**（A 0.33–0.53、B 0.62–0.81）⇒ **两帧在高光处的结构相关性弱**；**成因未定**（低 SNR / 1-LSB 量化 vs 位移），**不得读作运动证据、也不足以排除**。

**④ ⚠️ 由此暴露的一项未决口径（已登记 O141）** —— 本次**两版口径都无法给出"档间亮暗关系"的可用量化**：三判据法被量化污染；而"两帧皆亮"掩码（要求 `Low≥32 且 Normal≥8`）**存在像素选择偏差**——它只选到**双方都已接近饱和**的像素（该类像素占比中位 **0.000%–0.003%**），测出的"有效亮度比"因此**封顶在 ~8×（A）/ ~5×（B）**，**与标称 60–240× / 5.9–23.4× 无关**。⇒ **该测量结论不可用**（本档如实登记，**不据此宣称"渲染压缩了亮暗阶梯"**）；**要量化档间关系，须改从 CR3 按 O138 中性管线重渲（且须显式固定 auto-bright 关闭）后在 RAW 线性域测** ⇒ **登记为 O141**。

**⑤ 未做项（如实登记）** —— **未做目视复核**（本次全部为数值判定，**未出图人工核对**）；**A 的 `low3` 仅 8/29 场景可测**（样本严重不足）；**未做位移搜索**（本次未在窗内搜索平移，故"位移型拖影"未被定向排除）。
