## 1. 任务与一句话结论（用户 2026-09-24 指示）

用户指示：现场采集 **1 组 3 张 1080p 图**（曝光 **66 / 33 / 15 ms**），每张做两路对比 ——
① **HQ 路**：Retinexformer 用 **v1 / v2** 两个权重 + **ISP 自动处理**，三者比画质；② **ZDE++ 路**：ZDE++ 推理图 与 **ISP 自动处理**比画质，**特别是噪声**。

**结论（仅 F/G 受控对成立）**：

1. **ZDE++ 在 0.55 Lux 现场把暗部噪声放大约 `7.0–7.4×`，且为彩色斑点（蓝紫/绿）**——两组偏差 ≤0.2，**强可重复**。
2. **v2 的暗部噪声放大不随曝光缩短而恶化**（`3.6–4.6×` 全程稳定）；**v1 则从 66 ms 的 `~3×` 恶化到 15 ms 的 `~7.7–8.0×`**。
3. ⚠️ **「v1 与 v2 谁噪声更低」在本轮不可重复**：A 组（探索性）66 ms 支持 v2 更优（3.25× vs 2.23×），F/G（受控对）**同一档却支持 v1 更优**（v1 2.87/3.54× vs v2 3.63/3.90×）⇒ **不得据此换板端权重**。

## 3. 口径（可复现，全部写死在 `site_compare.py`）

| 环节 | 口径 |
|---|---|
| NV12 → RGB | **手写浮点 BT.601 / full range**（`R = Y + 1.402·v` / `G = Y − 0.344136·u − 0.714136·v` / `B = Y + 1.772·u`；`u,v = 色度 − 128`，色度按最近邻上采样）—— 与 §10.4 `isp.csc_matrix = "bt601"` + `isp.rgb_range = "full"` 一致；**Y 通道不做任何插值**（噪声原样保留） |
| HQ 路几何 | 内容等比缩放 **960×540** + 上下各 **2** 行零 pad → **960×544** → Retinexformer（PT FP32）→ 裁回 **960×540**（= 部署几何） |
| HQ 臂 | `LOL_v1.pth` / `LOL_v2_real.pth`（官方上游权重，`missing = unexpected = 0`） |
| ZDE++ 路几何 | 内容等比缩放 **480×270** + 上下各 **1** 行零 pad → **480×272** → `CurveEstimator`（`Epoch99.pth`，sha256 `ca8855b9…`）→ 曲线裁回内容 → **双线性上采样到 1920×1080** → **8 次迭代** `y ← y + x_r(y² − y)` → `clip[0,1]`（复刻演示链路的「曲线档估计 + 上采样 + 单遍 8 迭代融合」） |
| 噪声判据 | **32×32 块**（项目 D2 口径）：取**块均值最低 10 %** 的块，块内**灰度 σ 的中位** |
| ⭐ 公共暗块掩码 | 各尺度组的暗块**由基准臂（ISP）选定**，四臂测的是**同一批空间块**（避免各臂自选最暗块造成不可比） |
| 同尺度纪律 | ZDE++ 与 ISP 在 **1920×1080 原始网格**上比（无重采样）；v1/v2 与 **ISP 降到 960×540 后**同网格比 |
| 后处理 | **无**——禁 γ / 对比度 / 直方图均衡（规则 `10-evidence.md` §2）；视图复合仅加标签条 + 最近邻放大，**逐臂原样 PNG 无任何标注**（量化与归档以原样 PNG 为准） |
| 可比性自检 | 第 25 帧 vs 第 29 帧灰度平均差：F **0.80 / 0.82 / 0.93** LSB、G **0.73 / 0.83 / 0.88** LSB ⇒ 场景基本静止，三档曝光取自同一画面 |

## 4. 受控对结果（F / G）

### 4.1 ⭐ 暗部噪声放大倍数（**受控对可重复**）

放大倍数 = 该臂暗块 σ 中位 ÷ 同网格 ISP 暗块 σ 中位。

| 曝光 | F: ZDE++ / v1 / v2 | G: ZDE++ / v1 / v2 | 两组最大偏差 |
|---|---|---|---|
| 66 ms | **6.97** / 2.87 / 3.63 | **7.13** / 3.54 / 3.90 | 0.67 |
| 33 ms | **7.18** / 6.21 / 4.48 | **7.17** / 5.93 / 4.56 | 0.28 |
| 15 ms | **7.36** / 7.95 / 4.01 | **7.24** / 7.67 / 3.82 | 0.28 |

**读法**：
- **ZDE++ 稳定在 6.97–7.36×**（两组偏差 ≤0.16）⇒ 「ZDE++ 把 ISP 3DNR 后的残余噪声放大约 **7×**」是**可重复**的。
- **v2 对曝光不敏感**（3.63 → 4.01，G 组 3.90 → 3.82，跨档波动 <0.5）；
- **v1 随曝光缩短显著恶化**（2.87 → 7.95，G 组 3.54 → 7.67，**2.6× 劣化**）。
- ⚠️ **方向登记**：本轮**不支持**「v2 全面优于 v1」；**只在「短曝光（≤33 ms）」这一条件下 F/G 一致地支持 v2**。

### 4.2 亮度（灰度均值，0–255）

| 曝光 | F: ISP / v1 / v2 / ZDE++ | G: ISP / v1 / v2 / ZDE++ |
|---|---|---|
| 66 ms | 22.7 / 95.4 / 104.9 / 90.4 | 22.2 / 108.8 / 109.1 / 88.1 |
| 33 ms | 14.9 / 115.0 / 108.0 / 72.4 | 15.3 / 119.0 / 108.1 / 74.2 |
| 15 ms | 8.6 / 107.3 / 105.8 / 52.5 | 8.6 / 107.4 / 105.9 / 52.5 |

- **v1 / v2 输出亮度几乎不随曝光变化**（95–119），即两臂都做了「把输出钉到固定亮度」的归一——与「输入域亮度变化被网络吸收」一致。
- **ZDE++ 提亮倍数随曝光缩短而上升**（66 ms 4.0× → 15 ms 6.1×），但**绝对输出亮度随输入下降**（90 → 52）。
- **ISP 直出在三档下均偏暗**（22.7 / 14.9 / 8.6），0.55 Lux 现场按现有 O91 参数（66 ms + 20×）**不足以让 ISP 直出达到可用亮度**（呼应 §15 **O87**）。

## 5. 效力边界（必须随结论一起引用）

1. **非验收依据**；不进 §13 验收链、不改 §11.2 回归项、不改任何已裁取值。
2. **不构成板端权重变更依据**。板端 HQ 三档权重当前仍为 **`LOL_v1.pth`**（sha256 `9b4810dc…`）；本档只登记事实。换权重属 §15 **O11**：须先跑转换 + §11.2 闸口，并重跑 M0-2/3/4/5/8。
3. **样本面窄**：受控对 F/G 只覆盖 **一个机位 / 一个目标 / 一个照度 / 一次会话 / 每档单帧**；照度为**用户口头值，未用照度计**。
4. **镜头变焦环位置未记**（该镜头为 `1:1.6、3.6–10 mm 变焦`，见 O87；变焦环位置历来未记），故跨组亮度差异**不能**归因于单一因素。
5. **A–D、E 一律不作结论**（条件未受控）。
6. **ZDE++ 无 GT**（零参考模型）⇒ 本档只谈**噪声与亮度**，不涉及 PSNR/SSIM 类画质指标。
