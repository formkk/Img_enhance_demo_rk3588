## 1. 判定口径（`provisional` 的适用范围）

1. **定义**（§10.4）：以**代用数据**得出的取值可标 `provisional` 并**允许进入其阻塞里程碑**，但**必须在标注的复检时点转为 `final`**，否则该键视为**未定稿**。
2. **白名单**（规则 `10-evidence.md` §3）：`provisional` **仅适用于 §10.4 明列的代用数据项（M0 阶段、M1 复检）**；其余任何位置不得使用。
3. **禁区**：`docs/measurements.md` 的四张登记表（O19 / O21 / O23 / O24）**不允许 `provisional` 占位**——均为实测项，代用数据对该项无意义，**未测即未定稿**。
4. **与"空缺"的区别**：空缺（`null`）= 完全无依据；`provisional` = **有代用数据依据、但依据不合格**。二者在 §11.2-② 的判定中都**不是** `final`，但`provisional` 白名单项**不构成其阻塞里程碑的缺口**（§10.4）。

## 2. M0 出口时的 `provisional` 清单（1 键 + 2 结论）

| # | 键 / 结论 | 当前值 / 状态 | 依据（为何是代用） | 复检时点 | 清零条件（转 `final`） | 回退路径（不合格时） |
|---|---|---|---|---|---|---|
| P1 | **`pipeline.curve_level`**（含其"三档 shape 表"口径） | `"480x272"` | §4.3 的档位定档需 IMX415 **实拍**集，而实拍集在 M1 才有；M0 以代用数据先行（**O7** 裁定）。**M0-3 的 A/B 已执行（数值闸口过：两类 PSNR 44.13 / 46.15 dB，均 >35 dB；盲评 = 挂起，v3.43 裁定 O47）**，当前值另由 **O28-Q2** 裁定"维持默认档 480×272"支撑 | **M1**（实拍集产出后，按 §4.3 同一 A/B 规则复检；与 O11 全量重跑绑定） | A/B（实拍集）结论**支持** 480×272 → 转 `final` | A/B 结论指向其它档 → 改值并按 **O11** 重跑受影响的 M0-2/8 结论；本键不得滞留 `provisional` |
| P2 | **M0-3 的定档结论**（曲线估计分辨率 A/B） | **已产出（数值闸口过）**：代用数据（LOLv2 两类暗帧各 6 张、三档 FP16、应用域 512×288）下 480×272 vs 960×544 的 PSNR = 硬光源 **44.13 dB** / 均匀 **46.15 dB**（最小 40.99 / 40.84，均 >35 dB），照明均匀性两档几乎相同 ⇒ **维持默认档 480×272**；**盲评 = 挂起（v3.43 裁定 O47，待用户指示；口径 1 人 1 轮，v3.40 裁定 O46）** | 代用数据（O7 裁定；LOLv2 手机 ISP 域 ≠ IMX415 + RK ISP） | M1 | 同上（实拍集 A/B 支持 480×272 且盲评无差异）→ 转 `final` | 同上；**盲评若测出可感差异**，按 §4.3「出可见晕边 → 升档」处置并重跑 |
| P3 | **M0-8 的混合量化结论** | **已产出**：INT8 主线实测（480×272 双条带 **17.96 ms**、图像域 **51.07 dB**、双条带 **53.46 dB**，**已过 O27-①b 闸口**），**但校准集为代用集（50 张）**；**混合量化（输出层留 FP16）= 不可行（v3.41 收口）**——`auto_hybrid`/`quantized_hybrid_level` 为 no-op（与纯 INT8 逐位一致）、`w8a16`/`w4a16` 编译期拒绝、`w16a16i` 运行期失败 ⇒ 该子项关闭 | 代用校准集（O7 裁定；§10.2 步骤 4 的"无校准集"仅适用于 FP16 正式路径） | M1（实拍校准集产出后复检） | 实拍校准集复检**达标**（O27-①b 的 INT8 阈：张量 ≤3e-2 且图像域 ≥50 dB）→ 转 `final` | 不达标 → 回退 FP16 主线（§4.1）并重跑 M0-2/8 |

**合计**：**1 个键（P1）+ 2 条结论（P2 / P3）**。§10.4 中**没有**其它键被标为代用数据项 ⇒ 其余键一律不得使用 `provisional`。

## 4. M1 清零检查的操作口径（供 §11.2 的 M1-② 回归项使用）

1. **触发**：M1 实拍校准/评测集（≥200 张）产出，且 M1 权重一经变更（含实拍域 fine-tune）⇒ 按 **O11** 作废 M0-2/3/4/5/8 全部结论并**全量重跑**。
2. **逐项动作**：对 §2 的三项分别执行「复检 → 转 `final`」或「回退 → 重跑」；两项都不做 ⇒ 该键/结论**视为未定稿**，M1 不得出口。
3. **回写**：清零后须同步回写 §10.4（该键的定稿时点/标注）、§11.1-3/-8、`docs/measurements.md` 对应登记表的"复检时点"列，以及本清单（**M1 出口时本清单应为空**）。
4. **不得做的事**：① 用"下一阶段补跑"顶替清零；② 把 `provisional` 扩用到本清单之外的任何键或结论；③ 在四项实测登记表（O19/O21/O23/O24）中使用 `provisional`。
