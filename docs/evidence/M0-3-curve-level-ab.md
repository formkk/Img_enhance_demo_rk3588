## 1. 目的（§11.1-3）

按 §4.3 的定档规则，在**两类暗帧**（均匀暗光 + 单侧硬光源）上做**双档对比**：若 480×272（默认档）相对高精度档的画质差异在判据内，则**锁 480×272**；若出现可见晕边则升档。M0 阶段按 O7 裁定用**代用数据**先行定档，结论标 `provisional`，M1 实拍集复检。

## 2. 方法

| 项 | 设置 |
|---|---|
| 代用数据 | `refs/pre-research/lolv2/extracted/LOLv2/Real_captured/Test/Low`（100 张，**Test 集，与 U1 校准集 Train/Low 分离**） |
| 两类划分（客观指标） | 照度离散度 `spread=(max−min)/mean`（35×35 高斯模糊后）与亮区（P99）重心 (cx,cy)：**硬光源** = `spread>4` 且重心强偏离；**均匀** = `spread<1.9` 且重心居中。每类跨区间均匀取 **6 帧**（避免相邻近重复帧主导） |
| 档位（§4.3 三档） | **256×144 / 480×272 / 960×544**，**同用 FP16**（隔离"档位"变量；FP16 图像域已证 bit 不可分，见 M0-8 §9.2） |
| 几何（§3.1 G1） | 源图先**中心裁到 16:9**（真实系统原生 16:9，避免代用图 3:2 缩放畸变）→ 等比缩到有效区 256×144 / 480×270 / 960×540 → 上下零 pad 到模型 shape（0/1/2 行）；输出**只取有效区**、丢弃 pad 行 |
| 应用域 | **512×288**（§3.1 显示应用域，v3.33）；曲线场按 §3.1 I1 双线性上采样到应用域 |
| 应用实现 | `tools/enhance_ref.py` 的 8 次迭代参考实现（`y ← y + x_r(y²−y)` ×8，末端裁剪） |
| **参考档** | **960×544**（§4.3「升档」对照）；候选 = 256×144 / 480×272 |
| 指标 | 图像域 PSNR（vs 参考档）、最大/平均像素差、>1/>2 LSB 占比、照明均匀性（增强图低频 std） |
| 判据（§4.3） | 两类 PSNR **均 >35 dB** 且**盲评无差异** ⇒ 锁 480×272 |
| 测量条件随行 | 板型 **LubanCat-5 V2**（RK3588）；权重 **`Epoch99.pth` sha256 `ca8855b90df9a80f…`**；ONNX `zde_curve_480x272.onnx` sha256 `6fef7434ec7f04d3…`；精度档 **FP16**；曲线档 **256×144 / 480×272 / 960×544**；`librknnrt` sha256 `d31fc19c85b85f60…`（2.3.2）；`config.yaml` 快照 sha256 `96252090c3cf1d60…` |

## 3. 复现命令

```bash
# ① 选帧 + 两类划分 + 三档模型输入（PC，rknn232 环境；产物不入库）
$HOME/.conda/envs/rknn232/bin/python docs/evidence/reports/M0-3/scripts/step1_select.py

# ② 板端三档 FP16 曲线估计（u8 喂入，落盘曲线场）
ssh board 'cd ~/m0_3 && P=~/rknn_ab/probe/rknn_c_probe; M=~/rknn_ab/models; \
  for lv in 256x144 480x272 960x544; do for t in <tag 列表>; do \
  $P $M/zde_curve_${lv}_fp16_tk232.rknn inputs/${t}_${lv}.f32 5 nhwc float nosram u8 noperf curves/${t}_${lv}.f32 0 \
  > curves/${t}_${lv}.json; done; done'

# ③ 应用域 512×288 增强 + PSNR/均匀性 + 盲评材料
$HOME/.conda/envs/rknn232/bin/python docs/evidence/reports/M0-3/scripts/step2_apply.py
```

## 4. 结果

### 4.1 图像域 PSNR（vs 参考档 960×544，应用域 512×288）

| 类 | 档位 | PSNR 均值 | PSNR 最小 | PSNR 最大 | 最大像素差（LSB） |
|---|---|---|---|---|---|
| 单侧硬光源（6 帧） | **480×272** | **44.13 dB** | **40.99 dB** | 46.88 dB | 30.98 |
| 单侧硬光源（6 帧） | 256×144 | 39.46 dB | 36.36 dB | 41.47 dB | 46.95 |
| 均匀暗光（6 帧） | **480×272** | **46.15 dB** | **40.84 dB** | 53.91 dB | 14.26 |
| 均匀暗光（6 帧） | 256×144 | 41.94 dB | 37.92 dB | 49.02 dB | 23.53 |

**逐帧最小 PSNR**（480×272）：硬光源 `hard_00780` **40.99 dB**；均匀 `uniform_00728` **40.84 dB**。

### 4.2 照明均匀性（晕边代理指标）

增强图低频 std（大核模糊后的 std，反映照明均匀性）：**480×272 与 960×544 几乎相同**——如 `hard_00768` **19.041 vs 19.062**、`uniform_00726` **5.505 vs 5.443**、`uniform_00756` **14.077 vs 14.067**。⇒ **未测出低档引入的晕边/不均匀**（与 M0-8 §11.2 在代用素材上的目视观察一致）。

### 4.3 盲评材料

`docs/evidence/reports/M0-3/blind/<tag>_AB.png`（12 帧）：上排 A|B 为**应用域 1:1**（480 与 960 **随机化**），下排为**亮区 ROI 8× 放大**；答案键见 `apply_report.json` 的 `frames[*].blind`。**待 1 人 1 轮**（v3.40 裁定 O46，原 §13 的「≥2 人各 1 轮」）。

## 5. 判定（§11.1-3，`provisional`）

**两类 PSNR 均 >35 dB（480×272 最小 40.84 dB，余量 ≥5.8 dB）⇒ 数值闸口通过；按 §4.3 锁 480×272。**

| 判据 | 结论 |
|---|---|
| 单侧硬光源 PSNR >35 dB | ✅ **44.13 dB**（min 40.99） |
| 均匀暗光 PSNR >35 dB | ✅ **46.15 dB**（min 40.84） |
| 晕边/不均匀（照明均匀性） | ✅ 480 与 960 的低频 std 几乎相同，未测出差异 |
| 盲评无差异 | ⏸ **挂起**（v3.43 裁定 **O47**，用户指示："M0-3 挂起，直到我指示"）——材料已备（1 人 1 轮，v3.40 裁定 O46），**本轮不执行**；重启触发条件 = 用户指示 |
| 256×144 档 | 数值闸口亦过（min 36.36 dB），但 §4.3 定档规则锁默认档 480×272；该档仍可作为**画质/跟手性可选档**（§8.4） |

**依据**：480×272 相对 960×544 在两类代用暗帧上的图像域差异均落在 >35 dB 判据内，且未引入可测的晕边/不均匀 ⇒ **维持默认档 480×272**（`pipeline.curve_level="480x272"`，`provisional`）。**M1 实拍集产出后按同一规则复检**：合格转 `final`，不合格回退/升档并重跑（与 §15 O11 绑定）。

## 7. 边界与残留

1. **代用域**：LOLv2 为手机 ISP 域，非 IMX415 + RK ISP ⇒ 结论 `provisional`（O7），M1 复检。
2. **参考档选择**：以最高档 960×544 为参考（§4.3 的"升档"对照）；未以"应用域原生估计 512×288"为参考（该档为 §3.1 备用档、默认不转换）。
3. **采样实现**：曲线场上采样用 `cv2.INTER_LINEAR`（与 M0-8 §11 的目视对比同口径），**非**交付路径的 C/NEON 单遍融合实现；但该上采样对所有档位一致，不偏置档位比较。
4. **盲评 = 挂起**：数值闸口已过；盲评口径 = **1 人 1 轮**（v3.40 裁定 O46，原「≥2 人各 1 轮」），但按 **v3.43 裁定 O47**（用户指示）**本轮不执行**；重启触发条件 = 用户指示，届时执行并回填本节与判定表。
