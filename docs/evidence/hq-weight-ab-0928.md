### 2.1 三条**不利于 v2** 的现场证据

1. **明显偏色**：白墙发**品红/粉**、木桌发红、蓝染斑块变多（16× 最重）。LAB 上 `a_mean` 系统性 **+4~+5**（偏红）、`b_mean` **−3.5~−4.5**（偏蓝），**色度噪声 σ 高 1.7~2.5 倍**。
2. **暗部噪声更高**：16× **11.57 → 16.47**（1.42×）、20× **11.92 → 14.59**（1.22×）；仅 12× 档 v2 略好（17.53 → 16.59）。
3. **输出亮度被抬得过高**：v1 钉在 **~63**，v2 钉在 **87~102** —— 0.75 Lux 暗场景下 100 已偏过曝。

⚠️ **公平性注记**：v2 输出更亮 ⇒ 噪声与色度绝对值天然更大，故「暗块 σ」一列**不是完全公平的比较**；但 **LAB 色相偏移（a/b 均值）不是亮度造成的**，属真实色偏。

### 8.1 逐臂结论（目视 + 数值一致）

| 臂 | 目视 | 判定 |
|---|---|---|
| **`LOL_v1`** | 亮度适中、色彩最中性、色度噪声最低之一 | **综合最优（维持）** |
| `LOL_v2_real` | 更亮更花：白墙发品红、蓝斑多 | 亮度偏高、色偏明显 |
| `LOL_v2_synthetic` | **整体严重偏红/品红**（`a=144.2`、`b=117.1`、色度 σ 13.05 全场最高） | **不可用** |
| `NTIRE` | 亮度够但**颗粒极粗**（暗块 σ=21.47、SNR 1.00 = 噪声与信号同量级） | **不可用** |
| `SID` | **整幅蒙黄**（`b=148.9` vs 中性 127.2） | 暗部 SNR 最高但**色偏致命** |
| `SDSD_indoor` | 亮度中等、偏红品红、花 | 劣于 v1 |
| `SDSD_outdoor` | **太暗**（21.2，仅提亮 2.2×） | 提亮不足 |
| `FiveK` | **太暗且暗部死黑**（24.8、SNR 0.57 全场最差） | **不可用** |
| `SMID` | 亮度中等、噪声大偏红紫 | 劣于 v1 |

**综合结论**：**没有任何一臂在「亮度合适 + 暗部 SNR 高 + 色偏小」三项上同时优于 `LOL_v1`**。
各自的最强者各有致命短板：`SID` SNR 最高（4.55）但严重偏黄；`SDSD_outdoor` 色度 σ 最低（3.21）但亮度只有 21；
`NTIRE` 亮度好但 SNR 仅 1.00。⇒ **本项与 §2 的 A/B 一起，构成「维持 `LOL_v1`」的现场依据**。
